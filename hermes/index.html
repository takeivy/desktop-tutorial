In one minute

One record, six moves

Every step updates the same request, so staff, crews and residents all see the same status.

  1. ReportA resident reports it once, in about a minute.
  2. ReviewA person checks it before any work starts.
  3. Hand offOnly approved requests move to the crew.
  4. RouteThe workflow sets the steps and the owner.
  5. RespondThe crew fixes it and closes it on a phone.
  6. RevealStaff and the public see the same result.

Status Received → Assigned → Resolved Overdue: open more than 7 days

The point
One report. Nobody re‑typed it. Nobody chased it.

And the resident never had to call to ask where it was.

  • The record is created once and moves through every step.
  • Status changes are written by the system, not typed by a person.
  • The public sees the same truth the staff see, minus the staff fields.
